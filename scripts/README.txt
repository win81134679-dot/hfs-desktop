HFS Desktop
===========

方法一：單一 exe（最簡單）
  下載 HFS-Desktop-v*.exe，放在任何地方雙擊即可。
  第一次執行會自動從 GitHub 下載最新版 HFS，安裝到 %LOCALAPPDATA%\HFS Desktop，
  並套用雲端硬碟風格的分享網頁與預設設定（8080 埠、分享「下載\HFS分享」資料夾）。
  之後 HFS 有新版，程式會提醒你升級。

方法二：搭配自己下載的 HFS
  1. 到 https://github.com/rejetto/hfs/releases/latest 下載 hfs-windows-x64-*.zip，解壓到一個資料夾。
  2. 把這個 zip 的內容解壓到「同一個資料夾」，讓 hfs-gui.exe 和 hfs.exe 放在一起。
  3. 雙擊 hfs-gui.exe。

Windows 防火牆跳出詢問時，請勾選「私人網路」並允許。
